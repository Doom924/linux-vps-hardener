# Linux VPS Hardener — Автоматическая настройка, харденинг и оптимизация сети

Idempotent Bash-скрипт для быстрой базовой настройки новых Linux-серверов (**Ubuntu / Debian / AlmaLinux / Rocky Linux**).

## Что делает скрипт
1. **Стабилизация SSH-соединений:** настраивает `ClientAliveInterval`, `TCPKeepAlive` и отключает `UseDNS` в отдельном drop-in файле (`/etc/ssh/sshd_config.d/99-hardening.conf`), предотвращая обрывы сессий на зарубежных VPS.
2. **Безопасность без риска потерять доступ:** делает резервную копию конфигурации с таймстампом и проверяет синтаксис командой `sshd -t` перед перезапуском службы.
3. **Оптимизация сетевого стека ядра:** активирует алгоритм управления перегрузками **TCP BBR** и настраивает системные `tcp_keepalive_*` параметры через `sysctl`.
4. **Базовая защита периметра:** устанавливает и активирует **Fail2Ban** против брутфорс-атак и настраивает системный файрвол (`UFW` или `firewalld`), оставляя открытым SSH.

## Запуск на сервере
```bash
sudo bash harden.sh
```
